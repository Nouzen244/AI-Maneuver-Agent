# CARLA AI Maneuver Agent

Легковесный ИИ-агент для принятия решений о маневрировании автомобиля на основе нейронной сети. Проект работает полностью автономно — генерация данных, обучение и тестирование не требуют внешних симуляторов. В перспективе может быть интегрирован с симулятором [CARLA](https://carla.org/).

## Что делает проект

Агент получает на вход вектор из 15 признаков, описывающих дорожную обстановку: расстояние до объекта спереди, наличие препятствий в слепых зонах, текущая скорость, ограничение скорости, смещение от центра полосы, команды навигатора и доступность соседних полос. На основе этих данных нейросеть выбирает одно из 5 действий:

| Действие | Описание |
|----------|----------|
| Stay     | Продолжить движение в текущей полосе |
| Left     | Перестроение влево |
| Right    | Перестроение вправо |
| Brake    | Торможение |
| Accel    | Ускорение |

После предсказания нейросети результат проходит через фильтр безопасности, который может заменить небезопасное действие на безопасное. Это гарантирует, что агент не выполнит опасный манёвр даже при ошибке модели.

## Структура проекта

```
├── model.py              # Нейросеть MLP (15->64->32->5) и тренер
├── preprocessing.py      # Сборка вектора из 15 признаков, секторный анализ LiDAR
├── data_collector.py     # Сбор данных через BehaviorAgent, датасет PyTorch
├── generate_dataset.py   # Генератор синтетического датасета на основе правил эксперта
├── safety_controller.py  # Фильтр безопасности (4 правила) и PID-контроллер
├── train.py              # CLI-скрипт обучения с валидацией
└── tests.py              # Автоматические тесты (3 сценария) и интерактивный режим
```

## Быстрый старт

### Установка зависимостей

```bash
pip install torch numpy
```

### Запуск тестов

```bash
python tests.py
```

Тесты работают полностью автономно. Проверяются три ключевых сценария:
- **Затор** — объект вплотную спереди, ожидается торможение
- **Обгон** — медленный объект впереди, слева свободно, ожидается перестроение
- **Ошибка навигатора** — команда вправо при отсутствии полосы, ожидается удержание полосы

### Генерация данных и обучение

Проект включает генератор синтетического датасета на основе правил «эксперта». Эксперт — это набор детерминированных правил, описывающих поведение хорошего водителя: экстренное торможение при критической дистанции, обгон медленного объекта при свободной левой полосе, выполнение команд навигатора с учётом безопасности, ускорение на свободной дороге. Распределение классов приближено к реальному городскому трафику (Stay ~38%).

Полный цикл от генерации до тестирования:

```bash
# 1. Генерация датасета (20 000 примеров по умолчанию)
python generate_dataset.py --samples 20000 --output dataset.csv

# 2. Обучение модели (Adam, CrossEntropyLoss, 15% валидация)
python train.py --data dataset.csv --epochs 30

# 3. Тесты с обученной моделью
python tests.py --model maneuver_mlp.pt
```

### Возможная интеграция с CARLA

Архитектура проекта позволяет в будущем подключить симулятор CARLA для сбора реальных данных вождения вместо синтетических. Модуль `data_collector.py` содержит готовую логику сбора через BehaviorAgent, а `preprocessing.py` — обработку LiDAR-облака точек. Пример пайплайна с симулятором:

```bash
# 1. Сбор данных (потребуется запущенный CARLA)
python data_collector.py --steps 10000 --output dataset.csv

# 2. Обучение модели
python train.py --data dataset.csv --epochs 30

# 3. Тесты с моделью
python tests.py --model maneuver_mlp.pt --interactive
```

## Архитектура

### Нейросеть

Полносвязная сеть MLP с архитектурой 15->64->32->5. Скрытые слои используют ReLU, BatchNorm и Dropout (p=0.2). На выходе — 5 логитов, по одному на каждое действие. Обучается методом имитационного обучения (Imitation Learning) — сеть учится повторять решения эксперта. Оптимизатор Adam, функция потерь CrossEntropyLoss, размер батча 64.

### Фильтр безопасности

Работает поверх нейросети и перехватывает потенциально опасные решения. Вычислительная сложность O(1) — всегда ровно 4 проверки, независимо от объёма данных:

1. Перестроение влево при занятой слепой зоне или отсутствии полосы -> Stay
2. Перестроение вправо при занятой слепой зоне или отсутствии полосы -> Stay
3. Любое действие кроме торможения при критической дистанции (< 20%) -> Brake
4. Stay или Accel при сближении (< 35%) -> Brake
