# CARLA AI Maneuver Agent

Легковесный ИИ-агент для принятия решений о маневрировании автомобиля. Работает автономно в тестовом режиме и готов к интеграции с симулятором [CARLA](https://carla.org/).

## Что делает проект

Агент анализирует обстановку вокруг автомобиля (дистанции, полосы, слепые зоны) и выбирает одно из 5 действий:

| Действие | Описание |
|----------|----------|
| Stay     | Продолжить движение |
| Left     | Перестроение влево |
| Right    | Перестроение вправо |
| Brake    | Торможение |
| Accel    | Ускорение |

## Структура проекта

```
├── model.py              # Нейросеть MLP (15→64→32→5) и тренер
├── preprocessing.py      # Сборка вектора признаков, анализ LiDAR
├── data_collector.py     # Сбор данных, датасет PyTorch
├── generate_dataset.py   # Генератор синтетического датасета
├── safety_controller.py  # Фильтр безопасности и контроллер
├── train.py              # CLI-скрипт обучения
└── tests.py              # Автоматические и интерактивные тесты
```

## Быстрый старт

### Установка зависимостей

```bash
pip install torch numpy
```

### Запуск тестов (без CARLA)

```bash
python tests.py
```

Тесты работают полностью автономно — CARLA не требуется. Проверяются ключевые сценарии: предсказание модели, фильтр безопасности и пайплайн целиком.

### Генерация данных и обучение (без CARLA)

Проект включает генератор синтетического датасета — можно обучить модель полностью автономно, без симулятора:

```bash
# 1. Генерация датасета (20 000 примеров по умолчанию)
python generate_dataset.py --samples 20000 --output dataset.csv

# 2. Обучение модели
python train.py --data dataset.csv --epochs 30

# 3. Тесты с обученной моделью
python tests.py --model maneuver_mlp.pt
```

Генератор создаёт реалистичные сценарии вождения на основе правил «эксперта»: критическое торможение, обгон, навигация, ускорение на свободной дороге. Распределение классов приближено к реальному городскому трафику.

### Интеграция с CARLA

Проект спроектирован для подключения к CARLA. Полный пайплайн с симулятором:

```bash
# 1. Сбор данных (требуется запущенный CARLA)
python data_collector.py --steps 10000 --output dataset.csv

# 2. Обучение модели
python train.py --data dataset.csv --epochs 30

# 3. Тесты с моделью
python tests.py --model maneuver_mlp.pt --interactive
```

## Архитектура

**Нейросеть** — полносвязная MLP с BatchNorm и Dropout. Обучается методом имитационного обучения (Imitation Learning) на данных виртуального эксперта.

**Фильтр безопасности** перехватывает опасные решения сети:
- Блокирует перестроение при занятой полосе или слепой зоне
- Экстренное торможение при критической дистанции (< 20%)
- Упреждающее торможение при сближении (< 35%)

## Требования

- Python 3.8+
- PyTorch
- NumPy
- CARLA 0.9.x *(только для сбора данных и боевого режима)*
